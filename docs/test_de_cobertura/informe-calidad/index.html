    2. Resultado de las pruebas

    Se ejecutaron 1.370 pruebas automáticas que revisan el sistema de punta a punta: registro de usuarios, catálogo, carrito, pagos, envíos y facturación. Todas pasan: 846 del backend (Java) y 524 del frontend (React). Las 4 pruebas del carrito que fallaban quedaron corregidas y se listan abajo como evidencia.

    Backend: 361 pruebas unitarias (surefire) + 484 de integración (failsafe/Testcontainers) + escenarios Cucumber. Frontend: 49 archivos de prueba Vitest, 524 pruebas, todas verdes.

        4. Cumplimiento de requisitos

        El sistema debía cumplir 107 requisitos (funciones que debe hacer y condiciones de calidad). La verificación contra el código confirma que los 107 están implementados. Lo pendiente es actualizar el documento de requisitos, que todavía muestra 46 como “pendientes” por desfase documental.

        Validación cruzada entre docs/01-ANALYSIS/03-Requerimentos/requerimientos.md, endpoints REST, servicios, componentes del storefront y las suites de prueba. Incluye RF-070→076 y RNF-027→031, que solo viven en REQUERIMIENTOS_PENDIENTES.md.
