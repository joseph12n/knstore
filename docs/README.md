# Documentación del proyecto

Estructura de la documentación de KN-Store:

## Secciones

| Apartado                | Contenido                                                                  |
| ----------------------- | -------------------------------------------------------------------------- |
| `01-ANALYSIS/`          | Levantamiento de información, entrevistas, historias de usuario, BPMN, requerimientos (SRS), costos y marco teórico. |
| `02-DESING/`            | Casos de uso, diagramas de despliegue, clases, relacional, fichas técnicas y wireframes. |
| `03-DOCUMENTACION/`     | Documentación de gestión del proyecto: presentación (README), contexto para agentes (AGENTS), contribución (CONTRIBUTING) y validación del esquema MongoDB. |
| `cambios-proteccion-rutas.md` | Registro de la protección de rutas del frontend por rol.               |

## Convención

- Cada apartado numerado agrupa documentos de una fase o dominio.
- `03-DOCUMENTACION/README.md` es el índice del apartado y la presentación general del proyecto.
